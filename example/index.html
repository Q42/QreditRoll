QreditRoll with options

This page gives QreditRoll its own stylesheet and its own music, and switches the Konami code off:

<script src="https://qreditroll.com/qreditroll.js"
        data-theme="theme.css"
        data-music="music.mp3"
        data-konami="off"></script>

The credits come from this page's own humans.txt, found through <link rel="author">. The line "Music: Funny Song" is gone, because that song is not playing.

The page steers the roll with QreditRoll.start() (or QreditRoll.start({ silent: true }) for a roll without sound), QreditRoll.stop() and QreditRoll.scroll(), and hears from it through the qreditroll:start, qreditroll:stop and qreditroll:silent events. Try the buttons below; the wheel, a finger, the arrow keys and Escape work as on any site.
